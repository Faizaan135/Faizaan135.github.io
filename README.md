# ABBAS Engineering — GitHub Pages portfolio

This repository is the public site source for **ABBAS Engineering**, an independent engineering and product-development venture.

## Purpose
- Present real engineering work in FPGA, embedded systems and electronics.
- Publish measured results and engineering decisions as projects mature.
- Make GitHub repositories and project case studies easy to find.
- Avoid displaying private Notion and Google Drive records.

## Current projects
- **[AE-001 — Gesture Keyboard V2](https://github.com/Faizaan135/AE-001-Gesture-Keyboard-V2)** — requirements and feasibility; prototype performance is not yet validated.
- **[FPGA Professional Development](https://github.com/Faizaan135/fpga-professional-development)** — ongoing technical learning programme.

## Repository layout
- `index.html` — portfolio homepage.
- `assets/styles.css` — responsive styles, no framework or external assets required.
- `.nojekyll` — prevents Jekyll transformation of the static site.

## GitHub Pages setup
In this repository open **Settings → Pages → Build and deployment**. Choose **Deploy from a branch**, then `main` and `/(root)`. Save. A successful deployment should show a Visit site link under Pages settings.

## Maintenance
Update the content when work progresses, with associated evidence. Do not publish private files, emails, confidential material or unsupported performance figures.
